# PL/SQL GOTO and Functions Project

## Project Title
Employee Payroll Management System

## Introduction
This project is based on an Employee Payroll Management System. It was created to practice PL/SQL GOTO statements, stored functions, exception handling, and using functions in SQL queries.

## Project Contents

- 00_setup - Contains the tables and sample data.
- 01_goto - Contains the GOTO statement tasks (A1-A4).
- 02_functions - Contains the stored functions and payroll validation.
- 03_tests - Contains the test scripts.
- screenshots - Contains screenshots of the outputs.
- docs - Contains the reflection for the assignment.

## Database Tables

The project uses two main tables:

- departments - Stores department information.
- employees - Stores employee details such as salary, hire date, and department.

## Functions Created

The project includes functions for:

- Calculating annual salary
- Calculating years of service
- Calculating employee tax
- Finding an employee's department
- Validating payroll information

## How to Run

1. Run 00_setup/create_tables.sql.
2. Run the function scripts in 02_functions.
3. Run the GOTO programs in 01_goto.
4. Run the test scripts in 03_tests.
5. Check the output and screenshots.
