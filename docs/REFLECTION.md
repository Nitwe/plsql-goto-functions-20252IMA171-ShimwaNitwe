1. Reflection
 
1.1 What I Learned

Through this assignment, I learned how to use PL/SQL GOTO statements and stored functions in an Employee Payroll Management System.

1.2 GOTO Statements
I learned that GOTO can transfer program execution to a labeled statement. I also learned that GOTO should be used carefully because unrestricted jumps can make code difficult to understand and maintain.

1.3 Illegal GOTO
I learned that PL/SQL does not allow a GOTO statement to jump into certain restricted areas, such as inside an IF statement. The error was fixed by restructuring the code.

1.4 Stored Functions
I learned how to create functions that accept parameters, perform calculations or queries, and return a value. I created functions for annual salary, years of service, tax calculation, and department names.

1.5 Exception Handling
I learned how exception handling can prevent a program from failing unexpectedly. For example, the department function handles NO_DATA_FOUND and returns Unknown Department.

1.6 Functions in SQL
I learned that stored functions can be called directly inside a SELECT statement to calculate and display information for multiple employees.

1.7 GOTO vs Structured Programming
GOTO can be useful for demonstrating simple jumps in program execution, but structured programming using IF/ELSE and other control structures is generally easier to read and maintain.


So this assignment improved my understanding of PL/SQL control flow, stored functions, exception handling, and using functions with SQL queries. I also learned how these concepts can be applied to an Employee Payroll Management System.
